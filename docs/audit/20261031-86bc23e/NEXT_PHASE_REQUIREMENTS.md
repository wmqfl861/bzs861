# 下一阶段开发要求 — 2026-10-31 @ 86bc23e 审核后

## 阶段目标（来自用户阶段模板，结合审核事实校准）

≥2 个去重、真实审核且可用的**免费**底层来源（≥1 通用网页来源）
→ 多源搜索与部分失败报告
→ 显式读取选定 URL
→ 保存快照/正文/证据
→ 本地再次检索
→ 更新、删除和撤权正确生效。

**审核校准**：链路上"多源搜索框架/部分失败/显式读取/快照/证据/本地检索/删除/撤权"均已在离线回环验证（F-08/F-09 及能力表）。本阶段的真实增量是：**把已实现的管道接到真实免费来源上**（D1 批准后），并补齐审核发现的四个缺口（备份阻塞、TLS 策略与联网验证、排名基线、来源审批加固）。

## 阻塞与边界（不可协商）

- **D1 未答复前：不启用任何来源、不做真实爬取/付费调用/用户资料上传**（N4 标受阻，其余照常）。
- 模拟来源/论文馆藏来源**不能替代**通用网页验收；不得用收费接口或随机公共聚合实例补位；第三方入口必须完全免费（正常限流≠收费）；用户提供的模型可用且不受付费限制，但模型附带的收费搜索不自动获准。
- 不部署/调用 SearXNG、Scrapling、Firecrawl、Exa 作为执行后端；Beast/libxml2/SQLite 继续使用。
- schema15、B-24 范围、holdout、永久带键身份、隔离备份、owner/删除/撤权屏障、robots/预算/发布权限不放宽；83/161/10 与 37/46/0 不改口径。
- 已实现能力不倒退；分期≠删除需求（浏览器/多媒体/研究/订阅/分布式保留在总计划）。
- Linux 可做限定验收；Windows 未验证项如实标注，不签跨平台门禁。

## 验收覆盖矩阵（阶段完成判定，全部须有命令/退出码/日志证据）

1. 候选-谓词差分：随机语料上暴力 matches() 集合 == 搜索结果集合（预算≥语料，partial=false）。
2. 查询语法：整体引号字面量、`intitle:"C++ guide"` 字段短语、中英相邻（`中文hello`）、精确符号（`std::expected`/`C#`）、NOT/OR 组合——既有测试延续。
3. 正文纯度：`<main>正文</main><aside>广告` 不泄漏（html_selected_subtree 延续）+ 真实来源页面抽查。
4. 慢任务不阻塞：备份进行中 health/cancel/短请求在期限内；有界执行器满载 503。
5. 网络负例（回环夹具）：私网/DNS 变化/逐跳重定向/代理/解压炸弹/超时——netguard 现有测试延续 + TLS 策略单测。
6. 来源纪律：未审核/收费/禁用来源不执行；自写 review（无 attestation）在 load 被拒；同源不重复计票。
7. 部分失败：单源 429/超时，其余来源结果完整返回、partial=true、失败源带原因。
8. 读取质量：登录/挑战/错误页分类不冒充成功正文（现有 challenge/empty_content 逻辑在真实页抽查）。
9. 生命周期：快照更新、旧引用、删除、撤权、缓存隔离在真实来源会话中正确。
10. 稳定性：重启、worker 退出、旧租约、重复提交（幂等键）、取消、磁盘满（合成）。
11. 离线不变量：无模型配置时基础搜索/读取可运行；离线运行零出网（回环夹具断言）。
12. 诚实标注：真实网络未测项一律"回放通过、线上未验证"；Windows 未跑项标未验证。
13. 性能/质量阈值：在目标环境建立基线后冻结（排名基线打通后），不抄框架宣传数据。
