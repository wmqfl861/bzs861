# 启动版安全状态

本批不是经过独立安全审核的生产服务。真实 DNS/重定向/浏览器网络隔离、独立解析进程、细粒度共享权限和安全恢复的全范围工作包都未完成。

## 当前有效的控制

- 服务只绑定 IPv4 回环；没有远程 bind 参数，没有外部搜索/模型/抓取执行通道。
- Bearer 令牌需至少 32 字符；建议工具生成 256 位随机值。服务只保存 SHA-256，认证比较固定长度且不记录令牌。
- Linux/macOS 认证文件必须仅所有者可访问，状态目录设置 0700；Windows 文件 ACL 仍需所有者配置与实测。
- HTTP 标头 8 KiB，正文 2 MiB，64 连接上限，异步读写超时；输入会检查类型、重复键和复杂度。
- `contract.validate` 只执行纯配置校验。审核时钟与部署上限由服务端提供，客户端不能覆盖；校验结果不注册配置、不解除离线限制。
- HTML 拒绝外部声明，使用 NONET，有限遍历；**仍在核心进程，不能当作沙箱**。
- 数据操作绑定服务端主体；资源 ID 不是授权凭证；撤销后旧会话失败；旧任务 auth_epoch 不能再次发布。
- 暂停/取消提升 epoch，使旧任务不能提交；只有当前租约可将产物与终态一起提交。
- 快照只保存模型前的原文；当前无模型，不能被网页指令诱导调用工具。
- 备份本身是敏感数据，不含令牌文件并不意味着可以公开。备份默认带隔离标记；未实现安全恢复时拒绝提供恢复后的服务。

## 明确未解决

没有外网并不证明一般 SSRF 防护正确；没有公开 UI 并不证明未来 HTML 预览安全；没有向量索引并不证明未来向量权限已实现。当前 local 备份没有独立撤销账本或解除隔离流程。不要手动去掉隔离标记来冒充安全恢复。

本轮已使用独立子 Agent 核对交接需求和实际代码，修复另由主代理复核。具体范围与裁决见 [接手记录](handoff/TAKEOVER_20261017.md)；这不构成完整安全工作包或全产品的独立验收。

## 故障处置

磁盘满/配额满明确返回错误；不删除原始资料凑空间。先停止工作、备份可验证数据，再处理容量。SQLite WAL 不放共享网络盘；多个远程节点不可直接挂载同一数据库。

任何模型密钥、GitHub token、Cookie、用户网页、实际数据库或私有 auth 文件不得进入 Git。发现泄露时先通过对应提供方撤销凭据，再处理 Git 历史；仅删除工作目录中的文件不能撤销已公开凭据。

备份含所有用户的私有正文，但不包含独立认证文件。备份先写临时数据库，关闭并设置隔离标记后才发布；发布使用同卷硬链接，文件系统不支持时失败，不退回覆盖式复制。目录同步和断电故障注入尚未验收。
