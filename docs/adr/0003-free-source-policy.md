# ADR-0003：免费来源与执行准入

状态：采纳低频公开结果页与经审核免费 API 的路线，2026-10-18 整合澄清。本决策不批准任何具体来源；每个入口仍需独立审核和实测。

## 正常运行

1. 不接付费搜索/抓取回退，不依赖试用或赠送额度维持基础功能；公开免费入口的固定配额也必须遵守。
2. 每个启用来源携带完整 `source-manifest` 合同，包含已批准审核、`no_payment`、自动访问批准、条款/证据与有效日期。可用性、免费/使用条件、启用状态分别记录。
3. 运行 ID、provider、index_family、能力、适配器、端点及配额与合同一致；核心与 worker 各自检查，不能由客户端选源绕过。
4. 随包全部 17 条来源登记默认禁用，其中 13 个适配器仍未完成真实核验。即使某个页面能返回结果，也不能自动成为默认来源。
5. 按来源及适用共享范围限流、退避和冷却，遵守 Retry-After；相同查询缓存不能绕过新发生的禁用或审核过期。
6. 遇验证码、封禁或异常如实报告，不破解验证码，不用指纹/身份轮换绕过。
7. 来源和索引族分开。未知独立性不能自行拆成独立票；当前 DuckDuckGo 与 Bing 共用索引族，后续据证据调整。

不能根据过时的 API 费用或停用记录推导某个入口已经合格。新增或变更来源时核验其当前官方条件，并把证据放入审核记录；状态变更及时阻止后续请求。

## S0 候选探测

候选探测必须显式 `--include-candidates`，同时给出非空 `--only` 来源 ID；`--sources` 为清单文件路径。该入口只收集可达性与解析样本，不把候选提升为 approved 或 enabled。

S0 可用率与质量报告、来源合同审核、实际启用是三个独立步骤。S1 需至少 2 个真实可用来源，含 1 个经审核的通用网页源，并满足其余完成标准。原 C-10 与来源审核门槛继续有效。
