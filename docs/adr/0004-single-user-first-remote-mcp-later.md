# ADR-0004：单用户先行，远程 MCP 分期

状态：采纳单用户与远程接口排序，2026-10-18 整合澄清。该排序不删除已有权限、撤权、隔离备份或原验收语义。

## 当前阶段

S1–S4 优先本机单用户，保留既有 owner 隔离、令牌鉴权和发布前权限复核。MCP 首先使用 stdio；本机 HTTP 需要独立客户端令牌，不能开启无鉴权模式，也不能当作已完成公网服务。

按文档 tombstone 改善删除粒度：已删除对象的搜索、片段、证据、统计和在途任务不得重新发布；无关会话可继续。真实权限变化仍需失效或重新鉴权，不能把删除优化扩展为移除发布屏障。

## 恢复与等效要求

独立撤销日志和恢复隔离同样适用于单用户。当前备份继续隔离，无法证明最新撤销水位时不得恢复为可服务状态。S2 BACKUP-00 承接该门槛，S9 OPS-02 补长期演练；原 FT-080/C-11 保留，不改为按需可选。

多租户/细粒度授权可以随部署阶段实现，但第一次引入不同授权主体前必须完成隔离验收。功能 ID、预算和实现机制的变化不能删除原 AUTH-01、SESSION-01/02、API-01 的安全与恢复目标。

## S5 与后续

S5 远程 MCP 承接 TLS、每客户端令牌、限流、审计、权限收敛和按工具授权；后续业务功能随自身切片提供 MCP 映射。涉及多主体、私有资料、爬虫或任务控制时，在开放前落实对应授权边界。

传输可以变化，原会话冻结、取消、断线重取、背压和权限收紧后的处理需要等效验收。MCP 进度通知本身不证明这些性质已完成。
