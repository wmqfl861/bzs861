## 五阶段实现

| 阶段 | 变化 | 可见行为 |
|---|---|---|
| 1：页面响应顺序 | direct/read_many/crawl 捕获持久派发序号与快照；索引/摘要限制分开保存；旧 Worker 同样检查已报告的不完整回包 | 旧允许回包不能跨过新限制/删除；完整后发读取可以形成新表示，旧冻结表示不复活 |
| 2：任务保留 | 至少七天后的稳定终态明细压缩为永久有界摘要，无引用过期 robots 可回收 | jobs.compact 释放逻辑容量；key/计费保留，旧明细返回410 |
| 3：公平调度 | 成功接纳/预留租约同事务取得递增队列票号 | 已就绪任务逐次轮转，持续新任务不能总越过旧前沿；冷却/robots/预算仍决定资格 |
| 4：相关性评测 | evaluation prepare/freeze/run 冻结候选/外部标签/方法/阈值/环境/黄金身份 | nDCG@10、MRR@10、Precision@10 与缺标诊断可执行；完整 release_gate 保持blocked |
| 5：搜索会话 | 联网来源队列、不可变结果版本、版本游标、单调元数据事件 | web.search.start 支持断线重取、去重、取消、过期与背压；本地分页兼容 |

永久任务摘要最多8KiB，身份仍有每owner10000、部署50000的硬上限。活动/暂停/未结算不回收，未知预留须先正常结算；正文、证据、配额/冷却、派发序号和删除/发布水位保留。回收不代表无限容量或数据库文件立即缩小。见 [JOB_RETENTION](JOB_RETENTION.md)。

公平性针对同一类别中合格租约的机会，不承诺固定秒数的网络完成时间。旧版本未记录的真实同刻入队顺序无法重建，迁移保守处理。trap 延续既有版本规则，增加交错、重启和正常负例；不声称覆盖所有陷阱。见 [TASK_SCHEDULING](TASK_SCHEDULING.md)。

评测只覆盖 development/regression 固定候选。freeze 和每次run重新核对原黄金字节、manifest、完整查询投影和次序，才能通过有限门禁。工具不填人类等级、不提供holdout运行开关；没有真实人工质量成绩、来源消融、硬条件/引用正确率或独立人审身份认证。见 [RELEVANCE_EVALUATION](RELEVANCE_EVALUATION.md)。

会话复用核心索引族RRF，保留真实候选URL和已知链，去重键不代替策略身份。形成版本时已有的删除/noindex/nosnippet固定到旧版本，后来完整读取或重导入不能复活。事件只含状态/版本ID，内容分页重新鉴权；在途RPC可以结束，取消后不能发布。见 [SEARCH_SESSIONS](SEARCH_SESSIONS.md)。

## 规划与剩余验收

正式路线仍为 **S0–S9、83个工作包、161个原验收项**。本轮仅QA-02、SESSION-02从未开始转为部分实现，汇总 **36包部分实现、47包未开始、0包完整签收**。原包、依赖、估算、验收语义和历史来源保留；S0/S1/S2均未签署完整验收，测试数量不能折算产品完成度。

schema11按顺序保留schema8页面响应/派发身份、schema9任务摘要/robots引用、schema10持久队列，并增加联网会话。原迁移和隔离拒绝继续保留；旧数据丢失的历史身份不能补造，实际升级覆盖须查报告。

默认17搜索来源禁用、站点登记为空，本轮没有新增真实来源/站点批准。S0仍需在目标部署验证至少两个可用来源，其中包含通用网页源。0.1.2历史两次DNS失败不是本轮或用户环境测量。

QA-02继续需要真实人工标签/裁决、预冻结阈值与环境、来源消融、留出以及约束/引用证据。任务/会话需要真实长期运行、完整故障矩阵和后续分布式验收。跨owner公共集合、完整条件刷新、独立撤销日志及安全恢复连续性仍按原蓝图推进。任务摘要、页面水位和会话事件都不能解除恢复副本隔离。
