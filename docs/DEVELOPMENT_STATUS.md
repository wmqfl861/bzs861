# 开发进度：0.0.2 离线接手批次

日期：2026-10-17。计划基线仍为蓝图 v1.1 / 规格 v0.3；本文件只记录实现进度，不改变功能范围或计划估算。

## 实际完成的启动链

`固定来源发现 → 显式读取固定/本地内容 → HTML/TXT正文 → 不可变快照 → 全文/有界字面检索 → 冻结分页 → 原文证据 → 更新/删除同步`。

这是可编译、可运行的离线切片，不是联网搜索产品。固定源查询只发现元数据，不冒充已经读取正文。服务只监听 loopback，通过本地 HTTP 客户端访问；没有启动对公网的浏览器、网页获取或模型连接。

## 当前边界与已知限制

基础排序不代表已完成检索相关性指标；中文/符号等查询可能使用最多2000候选的扫描，结果明确注明partial。HTML解析在核心内执行，有大小与遍历限制但没有进程沙箱。备份包含所有用户内容且强制隔离；没有撤销对账时不能恢复成运行服务。用户在本机终端显式导入文件，并不等于网络接口可以读取任意服务器文件。
