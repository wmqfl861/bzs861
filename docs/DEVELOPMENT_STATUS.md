## 实现与边界

直接读取、read_many 和 crawl 在真实派发时保存持久发布序号。较新限制生效后返回的旧允许响应，会保存受限制的新表示；它不能恢复索引或旧摘要。逻辑 URL、最终 URL、中间跳转均检查限制和删除历史，owner 之间不传播限制。

`noindex` 与 `nosnippet` 分别保存限制代际。即使内容和限制值相同，新的限制响应仍推进序号，使交错的旧允许响应无法跨越；继承的限制不会污染明确后发、独立读取的新表示。冻结行在限制后保持撤回或摘要封闭，不因后来放宽或更换重定向目标而复活。

schema8 增加上述代际、持久派发身份和冻结摘要状态。schema7 在途任务的未知快照身份与已知空快照身份分开迁移；不能从旧数据推导不存在的历史。完整重读如经过新的发布水位，即使正文相同也可能产生新 snapshot；旧 snapshot 元数据不回写。
