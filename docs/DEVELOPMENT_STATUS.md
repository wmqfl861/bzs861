## 数据与权限

0.0.2 与原 Claude S1 都使用 schema 2，但结构不同。本轮采用 schema 3 识别两种来源并消除版本碰撞；不能直接把原 S1 二进制用于已有数据库。必须保留原始内容、快照/证据引用、删除状态、冻结会话边界和备份隔离。迁移验证由源码和本轮报告确认。

更新解析器不会自动清洗旧 HTML。按文档删除可以减少无关任务失效，但真实撤权和删除对象的发布屏障继续有效。没有可验证的撤销连续性，不允许把历史备份恢复为可服务状态。
