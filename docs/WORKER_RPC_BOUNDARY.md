# Worker RPC 控制面输入边界

HTTP 令牌认证及 Origin 拒绝先于读取/解析业务正文。原1 MiB传输限制不扩大；超限请求明确返回 HTTP413 / E_REQUEST_TOO_LARGE。认证成功不是跳过输入校验的理由。

信封仅接受 method、params 两个字段，method 是1..128字符的非空字符串。省略 params 才默认为空对象；显式 null、false、0、数组、字符串均拒绝。深度64、总节点20,000（包含对象键）、64位有符号整数、有限浮点数、合法UTF-8/Unicode为解码边界。解码后的重复键（包括转义形式）、非有限数、无效代理项均拒绝；字符串里的括号不会误算深度。

不合法输入返回 HTTP400 / E_PARAMS，不能调用业务方法、修改取消注册表或出站。未知方法仍为 E_METHOD；内部 KeyError 不再被误判为未知方法，内部异常不回显凭据或堆栈。现有合法业务参数错误、manifest mismatch、健康检查、取消及读取路径保持。

这不是未经认证的远程漏洞声明，也不是 OS 沙箱或全局 HTTP 连接数限制。请求解码界限是控制面稳健性措施，不扩大 Worker 来源、站点、robots、预算或网络权限。真实回环测试验证拒绝前无业务副作用；既有取消合同继续回归。
