## 复核重点

这批工作同时检查了新正文通道与原 `web.read` / `read_many`：旧文档不能因入口不同恢复被禁止的索引或摘要。有效头部/可解析 meta 限制在空正文与失败路径也生效；无有效正文的宽松响应只能保留原限制。重定向链中某一逻辑 URL 的限制不能被最终页面允许策略覆盖，而最终页面可保留自己的独立规则。

旧搜索会话必须保留当时正文的表示身份。A 原来读取 B、后来改为 C 时，冻结的 B 内容仍需遵守 B 后续的限制；不能只检查 A 当前指向 C。逻辑 URL、实际目标、不可变快照和删除身份分别处理。发布限制不销毁 owner 已有的完整私有正文和证据；删除请求仍使用原删除流程。

跨进程回执还校验已知用量、HTTP 状态、单跳性和共同报告的限制；无效 artifact 不抹掉有效用量或可信限制性观察。新增 MCP 在 SDK 解析前验证原始 JSON 和绝对 scope_path，避免显式范围变成省略参数。
