这五阶段是现有 S2 的连续开发增量。正式路线仍为 S0–S9，83 个工作包、161 个原验收项不变，不重写原依赖、估算或验收标准。每个阶段先复现缺口，再完成实现、针对性回归和独立复核；完整交付继续执行 Linux 普通 CTest、原生 ASan/UBSan、规划守卫及 Windows 原生/HTTP 阻塞检查。

阶段一最终完成17个独立公开API竞态场景、2个真实schema7同库在途升级及6个旧Worker不完整回包复核，共25例；完整Linux CTest 12套、原生ASan/UBSan 6套、原设计合同34项与规划守卫13项均通过。最初沙箱LeakSanitizer的ptrace环境失败原样保留，最终在兼容环境用同一二进制及leak检测参数通过。推送前新增复核发现旧Worker的截断/206/500回包可能误恢复限制，已补独立于发布字段版本的完整性检查；原候选与失败记录保留，当前结果使用修复后重新冻结的v2输入和完整重跑。详见[第一检查点报告](../../validation/s2_five_stages/stage1-report.json)。

阶段一已非强制发布为27966ffe61c16964c45d595e3ee2689115815217，远端tree与经过测试的本地tree相同。阶段一独立记录只证明0.1.6对应输入，不等同后续完整整合验证。后续四阶段进入0.1.8集成；实际最终门槛、GitHub发布和精确CI另由本轮最终报告记录，不能仅凭本地提交宣称远端已更新。


### 阶段 2：稳定终态明细回收

jobs.compact与接纳前有界维护压缩至少七天后的稳定终态网页任务明细，保留原身份/key/指纹和已知未知结算摘要。单份最多8KiB，永久身份每owner10000、部署50000。活动、暂停、pending/running和未结清预留不回收，未知执行不能借维护退款。robots同时检查准入和回执引用；正文、证据、配额/冷却、派发序号及删除/发布水位保留。

512项map明细占满后即使等待仍不能接纳的公开API基线保留；实现补容量恢复、永久身份/计费、owner隐藏、robots引用和事务回滚。候选作者/独立用例与最终统一门槛分别记录，不能把局部测试写成任意长期/断电验收。接口见[JOB_RETENTION](../JOB_RETENTION.md)。

### 阶段 3：持久公平调度与 trap 回归

批量读取与map/crawl分别使用持久队列，成功接纳、成功预留租约同事务取得递增票号并排到队尾；同键重提不重排，未知预留保留计费。新任务不能持续以零序号越过旧前沿。旧版本未保存的真实同刻入队顺序不能恢复，升级使用确定性保守顺序。

trap保留现有固定版本，增加交错、重启、日历族及正常文章/重复query键次序/版本号/有限数字ID负例；真实URL不因分类改写。原后台已给fixture、批读、map/crawl每类别一次机会，本阶段修类别内队列问题，阶段五再加入来源会话机会。见[TASK_SCHEDULING](../TASK_SCHEDULING.md)。

### 阶段 4：固定候选相关性评测

新增evaluation prepare/freeze/run，模板全为unjudged/grade:null，外部标签绑定证据、语料和方法。全池IDCG、固定Precision@10分母、MRR@10、覆盖/缺标诊断都有明确数学合同，empty/failed/unavailable不混淆。freeze及每次run重新校验原查询字节、manifest、完整非留出投影及次序，不能重算包哈希后替换黄金身份。

40条及20/15/5划分不变，没有holdout导出/运行开关。没有真实人工标签、来源消融、硬条件/引用正确率或独立人审认证，完整release_gate始终blocked。有限固定候选门禁只按预冻结方法、环境、阈值和外部证据判断，不代替FT-042/C-14签收。见[RELEVANCE_EVALUATION](../RELEVANCE_EVALUATION.md)。

### 阶段 5：冻结联网会话和事件重取

web.search.start接入持久来源队列和原C++ RRF，已完成来源响应产生不可变版本。session.get/events/cancel与版本绑定search.page提供单调元数据、重连、去重、取消、过期和背压，本地分页兼容。完整会话最多一小时，事件最多64个/十分钟，单次拉取最多32个；完整本地/联网会话每owner64、部署256，永久身份另有10000/100000上限。

事件不含查询/URL/标题/摘要/历史命中数，内容通过分页重新鉴权。真实贡献URL及已知链参与发布复核，绑定超界收紧，不以去重键代替政策身份。补充独立反例促使修复同源重复rank、旧本地容量、MCP原始类型、链完整性，以及形成版本时已经生效的删除/noindex/nosnippet上限；后来完整允许读取、重导入或改道不能恢复旧版本。见[SEARCH_SESSIONS](../SEARCH_SESSIONS.md)。
