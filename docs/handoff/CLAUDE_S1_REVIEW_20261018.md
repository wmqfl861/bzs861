## 4. 保留的原生合同边界

`model-config`、`source-manifest`、`search-request` 在 C++ 中执行结构和语义校验。保留空模型、角色缺省/null/继承、独立覆盖、深拷贝、可信上限、严格整数表示、URI、精确日期与 AND/eq、AST 与字节限制、1901/2038 日期边界。

`contract.validate` 和 `searchctl validate` 共用服务，响应 `validated=true, applied=false`。调用方不能提供时钟/硬限额；校验不注册配置、不读取凭据、不调用模型、不批准真实来源。固定合同并非通用 JSON Schema 引擎，也不自动提供完整 v1 搜索执行。见 [CONFIGURATION](../CONFIGURATION.md)。
