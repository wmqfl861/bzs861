## 实施与发布门槛

阶段 1、2 共用严格 Worker 条件协议；阶段 3、4 独立开发；阶段 5 在条件通路集成后复核。C++ 核心仍独占数据库、权限、预算与调度，Worker 负责受限网络与解析，MCP 只作参数映射。新接口若有，必须补对应 MCP；现有接口内部增强无需制造新工具。

每个实质变更需聚焦回归；作者结果、独立复核、最终集成运行分别留档。最后运行原合同、计划保持、原生 / HTTP / Worker / 真实 E2E，以及 ASan / UBSan 门槛。需要新 schema 时使用真实旧版本建立数据库后升级，保留旧快照、证据、删除和隔离性质。发布以精确父提交非强制更新，核对最终树、真实提交与该 SHA 的 Linux / Windows CI。
