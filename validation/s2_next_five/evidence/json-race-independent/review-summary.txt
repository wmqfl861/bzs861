根因证据
  本地实际链接 json-c 0.17-1build1；其序列化函数重置对象私有 printbuf 并返回内部地址，get/put 使用非原子的普通读改写指令。
  HTTP search_submit 的 normalized_request 位于 Store 锁外，可与后台 lease_next_search 的同一 contract.require_review 并发。
  validate_contract 的 guard_shape 和深拷贝调用 input.dump；逻辑只读并不等于 native 层不写。
  其他同类共享入口包括来源列举/搜索、会话 contracts.push/冻结结果字段读取，以及 SiteSpec.review。搜索缓存为字符串，已排除其自身共享 Json 图的候选。

同步设计复核
  一个进程生命周期 mutex 覆盖所有共享节点与别名。copy/get、dtor/put、lookup+retain、get+add 及隐式释放均使用同锁。
  dump/str 返回的 C++ 字符串及 keys 的键名复制都在锁内完成。类型辅助检查不与方法自身锁重叠；未发现递归锁死。
  parse/ShapeGuard 中的 tokenizer 和新树在发布前为线程私有，可不持共享 gate。canonical 组合已锁入口。
  工厂/at 返回 prvalue 由 C++20 保证复制消除。全局 Json 退出析构使用仍有效的进程生命周期 gate。
  合同仅承诺不可变共享树的并发读取及引用生命周期；并发修改、组合读改写、同一 Json 句柄的重赋值或生命周期需调用方同步。
